# Kochgram 📱

> **Полноценный клиент Telegram для iOS и Android** с официальным Telegram API (TDLibKit / MTProto), нативным интерфейсом на Swift & SwiftUI, встроенным Режимом призрака и защитой удалённых сообщений.

![Kochgram Icon](AppIcon.png)

---

## 🌟 Основные возможности

### 1. Настоящие сервера и официальный Telegram API
* Прямое подключение к инфраструктуре Telegram через **TDLib** (Telegram Database Library).
* Авторизация по номеру телефона, SMS-коду и облачному паролю двухфакторной аутентификации (2FA).
* Полная облачная синхронизация всех ваших реальных переписок, каналов, групп и медиа.
* Отправка текста, фото, видео, голосовых сообщений, файлов, стикеров и эмодзи.
* Ответы на сообщения (Reply), пересылка, реакции и редактирование сообщений.

---

### 2. ⚙️ Отдельный раздел «Настройки Kochgramma»

Раздел вынесен в настройках в отдельный выделенный блок с расширенным функционалом:

#### 👻 Режим призрака (Ghost Mode)
1. **Скрыть статус набора текста** — блокирует отправку событий «печатает…» собеседникам.
2. **Скрытое чтение сообщений** — открывает сообщения без отправки серверной отметки о прочтении.
3. **Скрытый просмотр историй** — просмотр сторис в режиме инкогнито.
4. **Индивидуальный призрак для каждого чата** — включение скрытности точечно для выбранных собеседников (свайпом или через меню диалога).
5. **Мастер-переключатель** — включение/выключение всех параметров призрака в один клик.

#### 🗑️ Удалённые сообщения (Anti-Delete)
1. **Локальное сохранение** — перехват и кэширование входящих сообщений на лету.
2. **Отображение удалённого контента** — если собеседник удаляет сообщение из диалога, Kochgram сохраняет его в чате и помечает плашкой **«Удалено в Telegram»**.
3. **Архив удалённых сообщений** — отдельный экран просмотра всех сохранённых удалённых сообщений с точным временем удаления.
4. **Управление хранилищем** — возможность быстрой очистки кэша и отключения сохранения.

## 🛠 Архитектура

* **Язык**: Swift 5.10+ / SwiftUI
* **Библиотеки**: `TDLibKit` (Swiftgram)
* **Минимальная версия iOS**: iOS 16.0+
* **Хранилище сессий**: Локальная база данных TDLib + зашифрованный защищённый кэш
* **Локальный кэш Kochgram**: `DeletedMessagesStore` (автономное JSON-хранилище)

## 🚀 Сборка проекта

### Сборка через XcodeGen (macOS / Xcode 16+):
```bash
brew install xcodegen
cd kochgramm
xcodegen generate
xcodebuild build -project kochgramm.xcodeproj -scheme kochgramm -sdk iphoneos -configuration Debug
```
Сборка IPA также автоматически выполняется в GitHub Actions (`.github/workflows/build.yml`).
